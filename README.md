# One Word From Grandma

> computor

The grandmother who sends this is seventy-nine, texts in lower case with one thumb, and has
just been shown the thing in her grandson's kitchen that writes back. She means *the computer*.
She is not afraid of it so much as unconvinced by it — and the missing `e` is her verdict.

## Run it

Requires Node 22 or newer (it runs the TypeScript as-is, standard library only, no network).

```
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`), UTF-8, no trailing newline.

To try it somewhere disposable:

```
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## Why this word

`computer` is the obvious entry and it loses. `computor` is not a misspelling of the machine,
it is her opinion of the machine: the same noun, typed by someone who is not going to look it
up. It is one token, eight characters, it reads cold with no caption, and the laugh arrives
before you have finished reading it. The full argument, including everything I rejected and
why, is in [shortlist.md](shortlist.md).
